# Requirements Document

## Introduction

本系统是一个用户权限管理系统，提供用户管理、权限管理、安全登录和权限展示功能。系统包含录入、查询、修改、打印等功能模块，并通过加密机制保护用户密码安全。

## Glossary

- **系统**: 用户权限管理系统（消费系统）
- **用户**: 系统中注册的个人账户，拥有特定的功能权限
- **权限**: 用户对系统功能模块及具体操作的访问许可（模块级 + 操作级）
- **密码哈希**: 将明文密码通过 MD5 算法转换为不可逆的哈希值
- **密码验证**: 将用户输入的密码进行 MD5 哈希后与数据库存储的哈希值进行比对
- **管理员**: 具有用户管理权限（添加、删除用户）的特殊角色
- **技术栈**: Python + Flask (后端) + MySQL (数据库) + HTML/CSS/JS (前端)

## Requirements

### Requirement 1: 用户注册与删除

**User Story:** AS 管理员，I want 添加和删除用户，so that 我能够管理系统中的用户账户

#### Acceptance Criteria

1. WHEN 管理员提交新用户信息（用户名、初始密码），系统 SHALL 将用户记录保存至数据库
2. WHEN 管理员选择删除指定用户，系统 SHALL 从数据库中移除该用户记录及其关联权限
3. IF 管理员尝试添加已存在的用户名，系统 SHALL 提示用户已存在并拒绝重复添加
4. IF 管理员尝试删除不存在的用户，系统 SHALL 提示用户不存在

### Requirement 2: 权限管理

**User Story:** AS 管理员，I want 为每个用户配置和保存权限，so that 用户只能访问被授权的功能模块

#### Acceptance Criteria

1. WHEN 管理员为用户分配功能模块权限（录入、查询、修改、打印），系统 SHALL 将权限关联保存至数据库
2. WHEN 管理员修改用户权限，系统 SHALL 更新数据库中的权限记录
3. WHILE 用户已注册，系统 SHALL 持久化保存该用户的所有权限配置
4. IF 用户尝试访问未被授权的功能模块，系统 SHALL 拒绝访问并提示权限不足

### Requirement 3: 用户登录界面

**User Story:** AS 用户，I want 通过图形界面输入用户名和密码进行登录，so that 我可以安全地访问系统

#### Acceptance Criteria

1. WHEN 系统启动，系统 SHALL 显示登录界面，包含用户名输入框、密码输入框和登录按钮
2. WHEN 用户输入用户名和密码并点击登录按钮，系统 SHALL 验证凭证的有效性
3. IF 用户输入的用户名不存在于数据库，系统 SHALL 显示"用户名不存在"错误信息
4. IF 用户输入的密码与数据库记录不匹配，系统 SHALL 显示"密码错误"错误信息
5. IF 用户连续 3 次输入错误密码，系统 SHALL 锁定该账户并提示联系管理员

### Requirement 4: 密码哈希存储与验证

**User Story:** AS 系统，I want 对密码进行 MD5 哈希存储和哈希验证，so that 用户密码信息得到安全保护

#### Acceptance Criteria

1. WHEN 新用户注册或修改密码，系统 SHALL 使用 MD5 算法对明文密码进行哈希计算
2. WHEN 系统将密码写入数据库，系统 SHALL 仅存储 MD5 哈希值
3. WHEN 用户登录验证，系统 SHALL 将输入的密码进行 MD5 哈希后与数据库存储的哈希值进行比对
4. WHEN 系统从数据库读取密码哈希值用于验证，系统 SHALL 直接比对哈希值是否一致
5. IF 哈希计算过程发生异常，系统 SHALL 记录错误日志并拒绝登录

### Requirement 5: 权限展示

**User Story:** AS 已登录用户，I want 登录后查看自己的权限列表，so that 我清楚自己可以使用的功能模块和操作

#### Acceptance Criteria

1. WHEN 用户成功通过身份验证，系统 SHALL 查询该用户的所有模块级和操作级权限记录
2. WHEN 用户登录成功，系统 SHALL 在主界面以表格或树形结构显示该用户拥有的所有功能模块权限及对应操作权限
3. WHILE 用户保持登录状态，系统 SHALL 根据用户的操作级权限动态启用或禁用对应功能按钮
4. IF 用户无任何功能权限，系统 SHALL 显示"暂无可用权限"提示
